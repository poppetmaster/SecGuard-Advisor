# Insumos ficticios de demostración

Estos archivos son material educativo ficticio para el recorrido de presentación. No contienen datos
de una organización real ni filas del CSV privado autorizado.

- `politica-respaldo-demo.md`: documento de caso ficticio sobre respaldo y restauración.
- `ficha-asistente-ia-demo.md`: ficha ficticia del asistente de IA del caso.
- `hallazgos-demo-ficticios.csv`: CSV compatible con el adaptador Qualys, con cinco filas ficticias.
  Se usa para mostrar validación, vista previa, confirmación y consulta estructurada.

El adaptador Qualys se probó por separado con un archivo real autorizado de 662 registros. En la
presentación solo se muestran agregados de esa aceptación; no se muestran filas ni valores privados.
