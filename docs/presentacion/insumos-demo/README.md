# Insumos ficticios de demostración

Estos archivos son material educativo ficticio para el recorrido de presentación. No contienen datos
de una organización real ni filas del CSV privado autorizado.

## Caso general de ciberseguridad empresarial

- `politica-acceso-remoto-demo.md`: política ficticia de acceso remoto, autenticación multifactor y
  revisión de accesos.
- `procedimiento-gestion-vulnerabilidades-demo.md`: procedimiento ficticio de plazos de remediación,
  excepciones y verificación del cierre.
- `hallazgos-demo-ficticios.csv`: CSV compatible con el adaptador Qualys, con cinco filas ficticias.
  Se usa para mostrar validación, vista previa, confirmación y consulta estructurada.

## Caso particular de IA (válido, no es el caso base)

- `politica-respaldo-demo.md`: documento ficticio sobre respaldo y restauración.
- `ficha-asistente-ia-demo.md`: ficha ficticia de un asistente interno de IA. Se conserva como
  ejemplo de un caso específico dentro del alcance general; no se usa como requisito de la demo.

El adaptador Qualys se probó por separado con un archivo real autorizado de 662 registros. En la
presentación solo se muestran agregados de esa aceptación; no se muestran filas ni valores privados.
